Pénétromètre — Guide de démarrage rapide Page 1 / 2 — Première mission

1 · Créer une nouvelle mission

Cliquez sur Fichier → Nouvelle mission (ou Ctrl+N). Remplissez les champs d'en-tête : Nom du chantier, Date, Opérateur (votre nom). Ces informations apparaissent sur toutes les fiches PDF exportées.
Cliquez sur ＋ Ajouter → Arbre vierge (ou Ctrl+T) pour créer le premier arbre de la mission. Le panneau de droite bascule en mode saisie.

2 · Onglet Identification

Saisissez le N° d'arbre (doit contenir au moins un chiffre : « 1 », « 12 bis »…), l'Essence et le Port.
Saisissez le Rayon (cm) — c'est la mesure la plus importante : elle borne toutes les PRBS. Le dessin se met à jour immédiatement. Renseignez aussi la Hauteur de sondage et l'Épaisseur d'écorce.
⚠ Sans rayon, le diagnostic est impossible
Si le rayon est à 0, l'onglet Sondages affiche un bandeau ambre et les altérations ne sont pas calculées. Saisissez toujours le rayon en premier.

3 · Onglet Sondages

La grille affiche les 16 directions (N, N-NE, NE…). Pour chaque direction sondée, saisissez la PRBS en cm (Paroi Résiduelle de Bois Sain) dans la colonne « Sain ». Descendez avec Entrée ou ↓.
La colonne Altéré (lecture seule) se calcule automatiquement : Altéré = Rayon − PRBS. Le dessin se met à jour en temps réel. Une case vide signifie direction non sondée (ignorée du diagnostic). Effacer une valeur supprime le sondage.
≥ 3 sondages sont requis pour un diagnostic fiable. En dessous, la pastille de la liste reste ◐ (partiel) et les exports masquent le t/R.

4 · Onglet Dégradations (optionnel)

Cliquez ＋ Ajouter pour déclarer une zone de bois altérée en périphérie (pourriture externe, blessure…). Définissez les grades début/fin et la profondeur. La dégradation est déduite du bois sain dans le diagnostic.

5 · Onglet Contreforts (optionnel)

Saisissez la longueur (cm) de chaque contrefort sur sa direction. Les contreforts gonflent le contour du dessin et sont pris en compte dans le rendu des dégradations externes.

6 · Dessin interactif

Le canvas central se met à jour à chaque frappe. Vous pouvez cliquer sur une direction libre pour y ajouter un sondage, ou cliquer sur un élément existant (sondage, dégradation, contrefort) pour l'éditer.

💡 Afficher / masquer les sondages
La case Afficher sondages sous le dessin contrôle les flèches sur le canvas et sur les exports PDF.

7 · Enregistrer

Cliquez sur 💾 Enregistrer (en bas à gauche) ou Ctrl+S. L'indicateur passe de ● Modifications non enregistrées à ✓ Enregistré. L'autosave protège votre travail toutes les 60 secondes en cas de crash — une fenêtre de reprise s'affiche automatiquement au prochain démarrage.

💡 Enchaîner les arbres rapidement
Utilisez ＋ Ajouter → Hériter du précédent pour reprendre l'essence, le port et les paramètres de protocole (mèche, hauteur, épaisseur d'écorce) sans les re-saisir. Naviguez entre les arbres avec Ctrl+PgDown / Ctrl+PgUp.

8 · Onglet Diagnostic

Le tableau PRBS par direction synthétise toutes les mesures. La colonne t/R (= PRBS / Rayon) est l'indicateur clé : plus il est bas, plus la paroi est mince et le risque élevé.
La Classe globale (Vert / Orange / Rouge) est calculée sur le t/R moyen des 16 directions. Elle s'affiche aussi dans la liste d'arbres à gauche.
Renseignez la Préconisation (urgence, échéance, texte libre) : ces champs sont repris dans la synthèse de mission et les fiches PDF.
Classe t/R moyen Signification Pastille liste
Vert > 0,33 Paroi résiduelle satisfaisante ● vert
Orange 0,20 – 0,33 Vigilance — surveillance recommandée ● orange
Rouge < 0,20 Risque élevé — intervention à planifier ● rouge
— N/A Moins de 3 sondages — diagnostic non fiable ◐ ou ○ gris

9 · Exporter

Par arbre :

Fiche PDF : bouton Exporter la fiche PDF dans l'onglet Diagnostic, ou Ctrl+E. Une page A4 avec dessin, tableau PRBS et préconisation.
Image PNG : bouton Exporter PNG — uniquement le dessin de section, sans tableau.

Mission complète :

Fiches PDF mission : Fichier → Exporter toutes les fiches (PDF) — un PDF multi-pages, une fiche par arbre.
Synthèse XLSX : Fichier → Exporter la synthèse mission (XLSX) — tableau de hiérarchisation du risque, trié, avec préconisations.
📂 Après chaque export
La barre d'état (en bas) affiche le nom du fichier et propose deux boutons : Ouvrir le fichier et Ouvrir le dossier — sans avoir à naviguer dans l'Explorateur.

11 · Conseils terrain

🔍 Filtres de la liste
Le champ de recherche filtre par n°, essence ou commentaire. La combobox filtre par classe de risque (Rouge / Orange / Vert / Non fiable). Le bouton ⏭ Prochain à finir saute au prochain arbre avec < 3 sondages.
↩ Undo / Redo
Ctrl+Z annule la dernière action, Ctrl+Y la rétablit. L'historique remonte jusqu'à 50 étapes.
💾 Sauvegarde et récupération
L'autosave écrit toutes les 60 s (si non enregistré). En cas de crash, une fenêtre de reprise s'affiche au prochain démarrage. Les sauvegardes glissantes (une copie horodatée par enregistrement) sont accessibles via Fichier → Ouvrir le dossier des sauvegardes.
🌐 Accessibilité
Affichage → Taille du texte : Petit / Normal / Grand / Très grand.
Affichage → Contraste élevé : texte plus sombre pour plein soleil.
Affichage → Langue : Français / English / Italiano.
📧 Aide et support
En cas de problème, utilisez Aide → Contacter le support dans l'application. Joignez le fichier de log (Aide → Ouvrir le fichier de log) à votre message. Contact : contact@silvavenir.fr
